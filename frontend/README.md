# Banao AI App Builder Frontend

Built with React (Vite) + Tailwind CSS.

## Setup
1. Run `npm install`
2. Copy `.env.example` to `.env` and adjust variables if needed.
3. Run `npm run dev` to start the frontend.

## Environment Variables
- `VITE_API_BASE_URL`: Base URL for your backend API
- `VITE_AGENT_HOST_TEMPLATE`: Template for the sandbox agent (use `${sandboxId}` placeholder)
- `VITE_PREVIEW_HOST_TEMPLATE`: Template for the sandbox preview (use `${sandboxId}` placeholder)
